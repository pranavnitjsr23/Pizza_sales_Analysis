# 🍕 Pizza Sales Analysis & Dashboard

This project analyzes a pizza restaurant's sales data using SQL to calculate key performance metrics and an interactive Excel dashboard to visualize the results.

## 🛠️ Tech Stack
* **SQL:** Data extraction, KPI calculations, and trend analysis.
* **Microsoft Excel:** Data visualization, pivot tables, and dynamic dashboards.

## 📊 Key Insights Extracted
* **High-Level KPIs:** Total revenue, average order value, and total pizzas sold.
* **Sales Trends:** Busiest days of the week and peak operating hours.
* **Product Performance:** Sales breakdown by category/size, plus the top 5 and bottom 5 best-selling pizzas.

## 📁 Repository Files
* `pizza_sales_queries.sql`: Contains all the commented SQL queries used for the analysis.
* `Pizza_Sales_Dashboard.xlsx`: The final interactive Excel dashboard.

## 🚀 How to Use
1. Run the `pizza_sales_queries.sql` script in your SQL environment to generate the necessary data views.
2. Open the `Pizza_Sales_Dashboard.xlsx` file to explore the charts, slicers, and visual insights.
